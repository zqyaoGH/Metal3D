# Metal3D - Apple Metal 3D渲染演示程序
这是一个基于Apple生态开发的3D图形渲染演示程序，聚焦Metal API的基础3D渲染能力实现，全程依托Xcode开发，结合Swift+SwiftUI完成界面与逻辑开发，最终实现相机轨道环绕3D立方体的核心效果。

## 📖 项目开发历程
### 1. 初始阶段：2D渲染的起点
新冠期间接触计算机图形渲染，仅了解OpenGL的前提下，在Xcode环境中用C、C+++OpenGL拼凑出一个2D图形渲染程序——实现了屏幕上移动的圆+内接三角形的效果。
随着macOS和Xcode多次版本升级，这个2D程序一度无法运行；退休后重新梳理代码，适配新版Xcode，让程序恢复运行。

### 2. 进阶尝试：从2D到3D的探索
为了将2D渲染升级为3D渲染，尝试深入学习计算机图形学、线性代数的矩阵变换理论（下载相关书籍但仅了解皮毛），逐步接触并理解3D渲染的核心空间概念：
- 世界空间、视图空间、裁剪空间
- 模型矩阵、视图矩阵、投影矩阵等基础矩阵知识

### 3. AI辅助开发：解决核心技术难题
借助主流AI编程工具完成3D程序的开发与完善，全程使用的AI工具及解决的问题如下：
| AI工具       | 核心作用                                                                 |
|--------------|--------------------------------------------------------------------------|
| 豆包         | 编程启蒙，协助搭建基础代码框架，实现功能迭代，解决Copilot for Xcode运行问题 |
| Minus        | 定位立方体/倒影渲染的buffer传值问题，搭建相机轨道lookAt方法基础框架       |
| OpenCode     | 终端交互式调试，协助分析相机轨道yaw角计算逻辑，摒弃复杂lookAt方法         |

#### 核心问题：相机轨道异常的解决过程
最初尝试用`lookAt`方法保证相机轨道启动时朝向世界空间原点，但出现立方体周期性消失的问题，经豆包、Minus调试均未解决；切换OpenCode后，通过以下步骤突破瓶颈：
1. 测试相机在关键位置（`(0, 1, 5)`、`(5, 1, 0)`、`(0, 1, -5)`、`(-5, 1, 0)`）的yaw角为0°、90°、180°、-90°，其实，就是0°、90°、180°、270°，因为`-90°`等价于`270°`、`-180°`等价于`180°`等，就是一个从0°到360°的完整循环
2. 摒弃复杂的`lookAt`方法，改用三角函数计算相机轨道：
   - 轨道启动时，通过相机位置确定轨道半径、高度及朝向原点的正确yaw角；
   - 定时器每次触发时，计算相机偏转0.5°后的新位置及对应yaw角；
   - 累计偏转360°后回到初始位置，实现相机轨道循环环绕。

最终相机轨道正常运转，程序达成预期目标。
