# Metal 3D 用户手册

## 1. 入门指南

### 系统要求
- macOS 10.15 或更高版本
- 支持 Metal 的 GPU（Intel 或 Apple Silicon）
- Xcode 13.0 或更高版本

### 项目设置
1. 使用 Xcode 打开 `Metal 3D.xcodeproj`。
2. 确保项目中的 Assets.xcassets 包含所有纹理资源（cube_texture_*.jpg, floor_texture.jpg, outer_space_*.jpg 等）。
3. 选择目标设备（iOS Simulator 或 macOS）并构建项目。

### 依赖项
- 无外部库依赖，仅使用系统框架（Metal, SwiftUI, Combine）。

## 2. 运行应用程序

启动应用后，您将看到一个分栏界面：
- **左侧面板**：控制控件和信息显示
- **右侧视图**：Metal 渲染的 3D 场景

初始场景显示一个纯色立方体、世界坐标轴和相机信息。

## 3. 控件和交互

### 相机控件
- **移动**：W（前）、S（后）、A（左）、D（右）、E（上）、Q（下）
- **视角**：拖动鼠标改变方向（Yaw/Pitch）
- **轨道模式**：点击“开始相机轨道”按钮，相机将围绕场景旋转
- **信息显示**：相机位置和姿态实时更新

### 对象操作
- **平移**：X/Y/Z 滑块调整立方体位置
- **旋转**：LA（纬度）、LO（经度）、AN（角度）控制旋转轴和角度
- **缩放**：SX/SY/SZ 滑块调整大小

### 特殊功能
- **自动旋转**：点击“开始自动旋转”按钮，立方体将自动旋转
- **背景颜色**：使用颜色选择器更改场景背景
- **演示切换**：按空格键循环渲染阶段

## 4. 演示阶段说明

按空格键或使用阶段标签切换：

- **实体颜色**（阶段 0）：纯色立方体，无纹理或光照
- **纹理贴图**（阶段 1）：立方体表面应用 6 面纹理
- **增加光照**（阶段 2）：添加 Phong 光照效果（环境光、漫反射、镜面反射）
- **增加地板**（阶段 3）：显示纹理地板，支持半透明
- **倒影+天空盒**（阶段 4）：添加天空盒背景、环境反射和地板镜像效果

## 5. 视觉特性

- **坐标轴**：RGB 线条表示世界坐标系（红 X、绿 Y、蓝 Z）
- **立方体映射**：表面反射周围环境，模拟金属材质
- **光照效果**：动态光照增强真实感
- **透明地板**：半透明纹理，支持倒影
- **天空盒**：360° 环境背景，提供沉浸式体验

## 6. 故障排除

### 常见问题
- **构建失败**：检查 Metal 着色器语法，确保 Xcode 版本兼容。
- **纹理不显示**：确认 Assets.xcassets 中的图片名称正确且已包含在目标中。
- **性能问题**：在低端 GPU 上降低分辨率或禁用复杂效果。
- **相机控制无响应**：确保应用窗口获得焦点，鼠标在 Metal 视图区域内。

### 性能优化
- 应用支持 60fps 渲染，实时显示 FPS。
- 纹理使用线性过滤，各向异性采样提升质量。
- 深度测试和 Alpha 混合优化渲染顺序。

### Metal 兼容性
- 确保设备支持 Metal 2.0 或更高版本。
- 在不支持的设备上，应用可能无法运行或显示错误。

如果遇到问题，请检查控制台输出以获取详细错误信息。
